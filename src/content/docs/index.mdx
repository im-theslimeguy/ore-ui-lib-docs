**Ore UI Library** (`ore-ui-lib`) is a client-side Java implementation of the **Minecraft Bedrock Ore UI** design system for Minecraft Java Edition (**Fabric** and **NeoForge**). Every component is built to match the Ore UI specification in game pixels, using layered bevels, damped spring physics, and dynamic GPU-rasterized typography.

- **Library Mod Only**: Installing `ore-ui-lib` on its own changes nothing in vanilla Minecraft — it provides UI primitives, widgets, and base screens (`OreScreen`, `OrePanelScreen`, `OreUi`) for mod developers.
- **Per-Component Docs**: Each component page includes a live interactive preview of the Ore UI design, design rules, full Java method signatures, parameter tables, and copy-pasteable Java examples.

Start with [Installation](/install/) or [Quick Start](/first-screen/).

## Supported Platforms

- **Minecraft**: `26.3` (Java `25`)
- **Mod Loaders**: Fabric (`>=0.19.3`) & NeoForge (`26.3+`)
- **Environment**: Client-side only (`se.miljo.beef.oreui.*`)
