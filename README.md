# Ore UI Library Documentation Site

This directory contains the official documentation website for **Ore UI Library**, built with [Astro](https://astro.build) and Tailwind CSS.

## Developing Locally

```bash
cd docs
npm install
npm run dev
```

The documentation site will start at `http://localhost:4321/`.

## Building for Production

```bash
cd docs
npm run build
```

The compiled static site will be generated in `docs/dist/`.
